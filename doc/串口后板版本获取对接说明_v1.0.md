# 门锁 ↔ WiFi 模块 后板版本获取对接说明

**版本**：v1.0（2026-10-21）

**背景**：云端物模型 `p_back_panel_version`（后面板版本号，string，maxLength 16）由门锁上报。但"后面板"就是 WiFi 模块本身，门锁无法自己知道，需通过串口向 WiFi 索取。

---

## 1. 新增命令

| 命令 | 方向 | payload | 应答 |
|---|---|---|---|
| **`0x68`** 获取后板版本 | **门锁 → WiFi** | 空 | **`0xE8` + 4 字节** |
| `0x21` 后板版本上报 | 门锁 → WiFi | `"V1.2.3.4\0"` | `0xA1`（空） |

- `0x68` 属普通请求帧（最高位 0），占用 `0x67`（时间查询）之后的空闲位
- `0xE8` = `0x68 | 0x80`，是 ACK 帧，**本身不再被应答**
- 走通用重传规则：**300 ms × 最多 2 次**

---

## 2. `0xE8` 的 payload（4 字节）

| 偏移 | 长度 | 内容 | 范围 |
|---|---|---|---|
| 0 | 1 | 主版本 | 0~255 |
| 1 | 1 | 次版本 | 0~255 |
| 2 | 1 | 修订号 | 0~255 |
| 3 | 1 | 构建号 | 0~255 |

**示例**：WiFi 版本为 `V1.2.3.4` → payload = `01 02 03 04`

> 门锁收到后格式化成字符串 `"V1.2.3.4"` 上报云端，最长 `"V255.255.255.255"`（15 字符 + 结尾 `\0` = 16 字节，正好等于 maxLength）。

---

## 3. 时序

```
门锁 : 入网成功（收到 0x65 成功）
  ├─ 0x30 "103\0"          语音包版本      → WiFi 回 0xB0
  ├─ 0x20 "V0.03\0"        前面板版本      → WiFi 回 0xA0
  └─ 回待机(idle) → 0x68（空）             → WiFi 回 0xE8 + 4 字节
       ├─ 门锁缓存为 "V1.2.3.4"
       └─ 0x21 "V1.2.3.4\0" 上报云端       → WiFi 回 0xA1

云端读属性时：
WiFi : 0x21（空，读请求）
门锁 : 0xA1 + "V1.2.3.4\0"
```

**请求策略**：

| 时机 | 说明 |
|---|---|
| 上电后首次进入待机 | 发一次 `0x68` |
| 每次休眠唤醒、回到待机时 | 若**仍未取到**版本，再发一次 |
| 已取到版本 | 不再请求（直到门锁重新上电） |

> 取不到就重试的设计意味着：WiFi **不实现 `0x68` 时，门锁每次唤醒都会多发一帧**（重传 2 次后放弃）。请务必实现。

---

## 4. WiFi 侧需要做的

1. **收到 `0x68`（空 payload）→ 回 `0xE8` + 4 字节版本号**（`主 次 修订 构建`，各 1 字节）
2. 收到 `0x21` 上报 → 回 `0xA1`（空），把 payload 交给 `ob_lock_prop_report_dispatch()`
3. 云端读 `p_back_panel_version` 时，`appsl_prop_opt_p_back_panel_version(opt=0)` 会发 `0x21` 空请求 —— 门锁回缓存值，WiFi 转给云端即可

---

## 5. 异常与兜底

| 情况 | 门锁行为 |
|---|---|
| WiFi 不回 `0xE8`（未实现/版本不支持） | 重传 2 次后放弃，**本次不上报 `0x21`**（避免假值上云） |
| 缓存为空时收到 `0x21` 读请求 | 回 `"V0.0.0.0\0"`（格式合法，表示尚未获取） |
| `0xE8` payload 少于 4 字节 | 忽略，不更新缓存 |

> **建议 WiFi 侧务必实现**：这条链路不通时，云端 `p_back_panel_version` 会一直是空。

---

## 6. 联调观察点

| 侧 | 日志 |
|---|---|
| 门锁 | `[uart tx] cmd=0x68, len=0` |
| 门锁 | `[uart rx] cmd=0xE8, len=4` |
| 门锁 | `[uart tx] cmd=0x21, len[8]`（`"V1.2.3.4\0"`） |
| WiFi | `uart tx, cmd=E8`（收到 `0x68` 后） |
| WiFi | 云端显示 `p_back_panel_version = "1.2.3.4"` |

**验收标准**：入网成功后 1 秒内，WiFi 日志出现 `0x68` 请求 → `0xE8` 应答 → `0x21` 上报，云端属性有值。

---

## 7. 注意

- `0x68` / `0xE8` / `0x21` 都是**普通命令**，`enc=1`，`key = random ^ K_L`
- 字符串 payload 一律以 `\0` 结尾（WiFi 侧 `strlen(value)` 取长度，接收缓冲区不保证以 0 结尾）
- 若 WiFi 尚未同步 `K_L`，`0x68` 会被丢弃、不回 `0xE8`；密钥同步完成后下次入网会自动恢复
