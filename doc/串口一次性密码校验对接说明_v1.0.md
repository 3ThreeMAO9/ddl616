# 门锁 ↔ WiFi 模块 一次性密码校验对接说明

**版本**：v1.0（2026-10-21）　**门锁侧已实现，等 WiFi 适配**

---

## 1. 用途

用户在门锁键盘输入 **6 位密码**后：

- 本地查不到这把永久密码 → **不再判失败**，改为通过串口请 WiFi 校验是否为**一次性密码（TOTP）**
- WiFi 回"通过" → 门锁开锁并记一条"一次性密码开锁"历史记录
- WiFi 回"失败"或 **1 秒内无应答** → 门锁按验证失败处理（播报失败、累计错误次数）

> 一次性密码在本地不占任何钥匙槽位，只用于开门，不能进菜单。

---

## 2. 命令定义

| 命令 | 方向 | payload | 应答 |
|---|---|---|---|
| **`0x69`** 校验请求 | **门锁 → WiFi** | 10 字节（见 2.1） | **`0xE9`** + 1 字节 |
| **`0xE9`** 校验结果 | **WiFi → 门锁** | 1 字节：`0`=通过，`1`=失败 | — |

### 2.1 `0x69` payload

| 偏移 | 长度 | 内容 | 说明 |
|---|---|---|---|
| 0 | 4 | UTC 时间戳 | uint32 小端，门锁当前时间 |
| 4 | 6 | 密码 | 每字节 **0~9**（数字值，**不是 ASCII `'0'~'9'`**） |

示例：UTC=`0x6AD6A4B5`、密码 `123456`
→ `B5 A4 D6 6A 01 02 03 04 05 06`

### 2.2 `0xE9` payload

| 值 | 含义 |
|---|---|
| `0x00` | 校验通过 |
| 其它 / 空包 | 校验失败（门锁按失败处理） |

---

## 3. WiFi 侧要做的

1. 收到 `0x69` → 取前 4 字节 UTC、后 6 字节密码
2. 调 `totp_verify(ts, pwd, 6)` → 结果转成 `0xE9` 回给门锁
3. **必须回 `0xE9`**（不回 = 门锁等 1 秒后判失败）

### 3.1 时间戳兜底

门锁时间来自 `0x66`/`0x67` 同步，**没同步过时是默认值 `1767225600`（2026-01-01）**：

```c
uint32_t ts = le32(payload);
if (ts < 1767225600) {          // 门锁还没对上时间
    ts = time(NULL);            // 用模组自己的时钟
}
ret = totp_verify(ts, payload + 4, 6);
```

### 3.2 ⚠️ 必须保证幂等（重传会重复收到）

门锁按通用规则**重传 2 次**（300ms 间隔），所以同一个密码可能在 1 秒内到达 **2~3 次**。

而 `totp_verify` 命中后会把这个 `(T, index)` **标记为已使用**，第二次调用会返回失败 → 门锁收到"失败"就把人拒了。

**要求**：记住最近成功过的 `(T, index)`（或密码原文 + 时间窗），重传命中时**仍回 `0`**：

```c
if (is_recent_success(ts_window, index)) {
    reply(0);                   // 刚才那次的重传
    return;
}
```

---

## 4. 时序

```
用户输入 6 位 + 确认
  → 门锁本地验证失败
  → 0x69（UTC + 密码）
       ├─ 300ms 未回 → 重传（最多 2 次）
       └─ WiFi 回 0xE9
              ├─ 0 → 写开锁记录(一次性密码) → 开锁
              └─ 1 / 空 → 播"验证失败" + 累计错误次数

1 秒内始终没有 0xE9
  → 门锁判失败（同上）
```

---

## 5. 异常处理

| 情况 | 门锁行为 |
|---|---|
| WiFi 未联网 / 不会回 | 1 秒超时 → 判失败 |
| `0xE9` 空包 | 判失败 |
| 超时后才收到 `0xE9` | 丢弃（不会补开锁） |
| 用户连续试多次 | 每次都发一次 `0x69`，无本地频率限制（防重放由 `totp_verify` 保证） |

---

## 6. 联调验证

| 观察点 | 期望 |
|---|---|
| 门锁日志 | `[uart tx] cmd=0x69, len[10]` |
| 门锁日志 | `[uart rx] cmd=0xE9, len=1`（值 0 或 1） |
| 通过 | 电机开锁 + 历史记录中出现"一次性密码开锁" |
| 失败 | 播报"验证失败"，错误次数 +1 |

**验收标准**：用 APP 生成的一次性密码，1 秒内开锁；重复使用同一密码应失败（防重放）。

---

## 7. 注意

- `0x69` / `0xE9` 都是**普通命令**，`enc=1`，`key = random ^ K_L`
- 密码 payload 是**数字 0~9**，不是 ASCII
- 门锁不会主动告知"这个密码已用过"，防重放完全由 WiFi 侧 `totp_verify` 的已用标记负责
